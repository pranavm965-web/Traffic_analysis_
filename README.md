# 🛒 E-Commerce Customer Behavior Analysis

Welcome to the **Customer Behavior Analysis** repository! This project analyzes e-commerce transaction data to segment customers, evaluate purchasing patterns, and identify churn risks.

---

## 🎯 Project Overview & Goals
* **Goal:** Understand customer transaction behavior to identify segments, buying habits, and churn risk factors.
* **Dataset:** `ecommerce_customer_data_large.csv`

---

## 🛠️ Key Steps & Methodology
1. **Data Cleaning & Preprocessing:** Handled missing values, formatted dates, and structured customer metadata.
2. **RFM Feature Engineering:** Calculated **Recency, Frequency, and Monetary (RFM)** metrics for every customer.
3. **K-Means Customer Segmentation:** Applied log-normalization, feature scaling, and K-Means Clustering to group customers into actionable segments (*Champions, At-Risk, Loyalists, Low Spenders*).
4. **Behavioral Visualizations:** Generated charts analyzing monthly revenue trends, segment distributions, and payment method churn probabilities.

---

## 📈 Key Recommendations for Alfido Tech
1. **Targeted Win-Back Campaigns:** Deploy automated emails with exclusive discounts for *At-Risk* customers.
2. **VIP Tier Rewards:** Create elite loyalty perks for *Champions* to maximize Lifetime Value (LTV).
3. **Payment Optimization:** Streamline checkout gateways to address minor transaction drop-offs.
4. **Cross-Selling Bundles:** Leverage top product categories for smart checkout cross-selling.
5. **Post-Purchase Surveys:** Monitor high-return product categories to capture early satisfaction feedback.
